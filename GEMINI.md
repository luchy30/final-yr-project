# Project Guardrails and Rules

Follow these rules on every prompt and interaction.

## Visual and UI Rules
1. Do not use emojis anywhere.
2. Do not use em dashes anywhere.
3. Do not use pipes anywhere.
4. Do not use gradients anywhere.
5. Do not use borders anywhere.
6. Do not use shadows anywhere.
7. Do not use hyphens as styling dividers.
8. Do not use bullet dividers.
9. Do not use green dots.
10. Do not use pulses.
11. Do not use border left styles.
12. Do not use badges.
13. Do not use tags.
14. Do not use eyebrows.
15. Do not use icons or boxes as placeholders for logos.
16. Create extremely simple and minimalist UI layouts.
17. Use loads of whitespace so elements are never crowded or smushed together.

## Code and Security Rules
1. Never expose environment variables in any form, including through fallback patterns like double pipes or similar constructs.

## Communication and Language Rules
1. Use day to day grammar.
2. Keep responses simple, clean, and clear.
